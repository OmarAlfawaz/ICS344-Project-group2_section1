# SSH Brute Force Exploit (Metasploit & Custom Python Script)


Phase 1 demonstrates two approaches to brute-forcing SSH credentials:
- Using **Metasploit's `ssh_login` auxiliary module**
- A **custom Python script** leveraging `paramiko`

---

## 🧰 Requirements

- Kali Linux (or compatible penetration testing environment)
- Python 3.7+
- Metasploit Framework
- `paramiko` (for the custom script)
